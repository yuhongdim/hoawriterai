Security & Reliability

Use secure workflows and optional server proxies to protect data and API keys.

Recommendations

  • Store keys in environment variables on the server.
  • Rate limit and validate request payloads.
  • Provide graceful fallback to local generation.

Proxy Integration Example

POST /api/generate
Authorization: Bearer <server-issued token>
{
  "prompt": "Draft HOA violation letter...",
  "temperature": 0.2
}

Server verifies token → calls model provider with server‑side key → returns plain text.
